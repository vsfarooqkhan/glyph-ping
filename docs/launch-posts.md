## Reddit: r/NothingTech / r/NothingPhone

**Title:**
I made a free, open-source Glyph Toy that shows who's messaging you (WhatsApp, Snapchat, Instagram, Teams) on the Phone (3) matrix

**Body:**
I kept flipping my Phone (3) over just to check who'd messaged me, so I built **Glyph Pings**.

When a message arrives, the app's logo pops up on the Glyph Matrix and the sender's name scrolls across, like the caller ID scroll. 📹 Video above.

**What it does**
- WhatsApp, Snapchat, Instagram and Microsoft Teams
- Group chats show as "Rahul in Weekend plans" (you can turn groups off)
- **Names only** by default; turn on message text if you want it
- Unread dots stay until you read the notification
- Long-press the Glyph Button to replay, hold to clear
- Works as an Always-on toy, so it shows with the screen off

**Privacy:** it reads notifications, so: **no internet permission**, nothing is saved, and the code is open source so you can check.

**Download (free APK) + source:** https://github.com/<your-username>/GlyphPings

**How to set it up**
1. Install the APK from GitHub Releases
2. Allow notification access in the app
3. Settings → Glyph Interface → Glyph Toys → enable **Pings** (and set it as the Always-on toy)
